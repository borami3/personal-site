# Bolu Aminu — personal site

A static site: `index.html` plus `headshot.jpg`. No build step.

## Deploy on Vercel
1. Put this folder in a GitHub repo (or drag it into vercel.com/new).
2. Import it in Vercel. Framework preset: **Other**. Leave build and output settings empty.
3. Deploy.

Or from a terminal in this folder: `npx vercel` (then `npx vercel --prod`).

## Before going live
- Resume links point to the Google Drive file. Make sure its sharing is set to "Anyone with the link".
